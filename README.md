# سنابل الآخرة 🌿

تطبيق ويب تقدّمي (PWA) باللغة العربية، بواجهة RTL وهوية هندسية إسلامية بالأخضر والأبيض.

## تشغيل محلي
افتح `index.html` في متصفح حديث. لتجربة التثبيت والعمل دون اتصال بشكل كامل، شغّل المشروع عبر خادم محلي أو انشره على GitHub Pages.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً باسم `sanabel-alakhira`.
2. ارفع جميع الملفات الموجودة في هذا المجلد إلى جذر المستودع.
3. من Settings → Pages اختر النشر من الفرع `main` والمجلد `/ (root)`.
4. انتظر اكتمال النشر وافتح رابط GitHub Pages.

## الموجود في هذه النسخة
- واجهة عربية متجاوبة وهوية خضراء وبيضاء.
- تنقّل بين أقسام الصلاة، والمناسبات، والأدعية، والزيارات، والتعقيبات، والمسبحة والإعدادات.
- حفظ المدينة والإعدادات والمسبحة محلياً.
- وضع داكن.
- دعم أولي للتثبيت والعمل دون اتصال عبر Service Worker.

## ما يزال يحتاج إلى استكمال قبل الاعتماد
- ربط مواقيت الصلاة بمكتبة/مصدر حساب موثوق واختبارها حسب المدينة وطريقة الحساب.
- تفعيل جدولة الأذان والإشعارات الفعلية على Android.
- إدخال النصوص الكاملة للزيارات والتعقيبات من مصادر موثوقة ومراجعتها.
- إضافة قاعدة مناسبات دقيقة وتوثيق تواريخها.
- اختبار التثبيت والأداء على أجهزة فعلية.

هذه نسخة أولية قابلة للتطوير، وليست إصداراً نهائياً جاهزاً للاستخدام الديني دون مراجعة.
